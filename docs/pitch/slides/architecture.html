Catena-X Traceability · 8

The app is the only new component. The EDC, the registry, the submodel server and the identity are what every participant runs anyway. All dataspace access goes through the official Tractus-X SDK behind our own interfaces, so moving to the next release (26.09: EDC 0.13) is a configuration and adapter change, not a rewrite. Setting it up takes an admin sign-in and a guided checklist on the Setup page: connector, registry, IdP, discovery and the company's own root CA, each with a connection test, and the usage policies the company accepts. Next to the one-level read across companies, the core shows a part's structure through every own level and where a part is used, and checks the own bills of material and the partners' connectors.
